ImGen9 ทำอะไร

ImGen9 เปลี่ยนภาพตัวละคร 1 ภาพ ให้เป็น sprite 2D ครบ 8 ทิศ พร้อมใช้ในเกม มีท่ายืน เดิน โจมตี เจ็บ และตาย ได้ไฟล์ atlas + JSON สำหรับเกมเว็บ (PixiJS / Phaser), ภาพรายเฟรม, GIF และไฟล์ .spr/.act

ImGen9 ไม่ได้วาดภาพเอง คนวาดคือ AI ของคุณ (Gemini, ChatGPT ฯลฯ) จาก prompt ที่ ImGen9 เขียนให้ ส่วน ImGen9 ทำงานจุกจิกรอบๆ ให้: ลบพื้นหลัง ตัดเฟรม ตรวจเฟรม จัดเท้าให้ตรง ทำ 8 ทิศจากภาพ 2 มุม และประกอบไฟล์

① อัปโหลด② บรรยายตัวละคร③ ภาพอ้างอิง (ไม่บังคับ) ④ ให้ AI วาดท่าทาง⑤ ดาวน์โหลด

ขั้นตอนอยู่ในแถบขวาของแท็บ Pipeline ขั้นที่ต้องทำต่อจะเปิดไว้ให้ ขั้นที่เสร็จแล้วขึ้น ✓ แถบบนสุดของหน้าบอกขั้นต่อไป (กด ไปที่การ์ดนี้ ↓) และหัวการ์ดทุกใบมีป้าย: ต้องทำ · ไม่บังคับ (ข้ามได้ เช่น ภาพมุมมอง อาวุธ หมวก สีใหม่) · ระบบทำเอง · ✓ เสร็จแล้ว

ก่อนเริ่ม

  • บัญชี AI วาดภาพ ที่แนบภาพได้ เช่น Google Gemini หรือ ChatGPT
  • ภาพตัวละคร ที่คุณสร้างเองหรือมีสิทธิ์ใช้: ตัวเดียว เต็มตัว พื้นหลังเรียบ ถ้าเป็นแผ่น turnaround (หน้า / เฉียง 3/4 / ข้าง / หลัง เรียงกัน) จะได้ผลดีกว่า
  • การลบพื้นหลังครั้งแรกสุด ระบบจะดาวน์โหลดโมเดล (~180 MB) ครั้งเดียว อัปโหลดแรกจึงใช้เวลาราว 1 นาที ครั้งต่อไปเหลือไม่กี่วินาที
  • เปิด ImGen9 ครั้งต่อไป: Windows ดับเบิลคลิก run.bat · macOS ดับเบิลคลิก run.command (ต้องมี Python 3.11–3.13 จาก python.org หรือ Homebrew) · Linux พิมพ์ sh run.sh แล้วเปิด http://127.0.0.1:8000

💡 ยังไม่มีตัวละคร? ให้ AI วาดแผ่น turnaround ก่อน ตัวอย่างคำขอ: “Character design turnaround sheet for a 2D isometric RPG: [ใคร ทรงผม ชุด สี อาวุธ]. Four full-body views side by side (front, front three-quarter facing bottom-left, side facing left, back), relaxed standing pose, plain white background, no shadows, no text.”

🔌 การเชื่อมต่อ

ปุ่ม 🔌 การเชื่อมต่อ บนแถบด้านบน (เปิดเองตอนใช้ครั้งแรก) บอกว่าอะไรจำเป็น อะไรไม่จำเป็น ตรวจในเครื่องคุณเท่านั้น:

  • จำเป็น: AI วาดภาพบนเว็บ (Gemini หรือ ChatGPT) สำหรับวาดท่าทาง เลือกตัวที่ใช้ แล้วทุก prompt จะเขียนให้ตัวนั้น
  • ไม่จำเป็น: ผู้ช่วย AI ในแชท (Claude Code, Gemini CLI หรือ Codex ตัวไหนก็ได้ที่ติดตั้งไว้) ช่วยกรอกข้อมูลตัวละครและตรวจงานภาพ · API key (แสดงแค่ว่าตั้งแล้วหรือยัง) · Blender สำหรับเส้นทาง 3D

ไม่มีส่วนที่ไม่จำเป็นก็ใช้งานได้ แค่พิมพ์คำบรรยายตัวละครเอง · ImGen9 ไม่เข้าไปดูเบราว์เซอร์หรือการเข้าสู่ระบบของคุณ

โปรเจกต์และตัวละคร

โปรเจกต์ คือกลุ่มตัวละครของเกมเดียวกัน (หรือธีมเดียวกัน) เช่น “My RPG” ตัวละครทุกตัวอยู่ในโปรเจกต์ใดโปรเจกต์หนึ่ง ถ้ายังไม่สร้าง ตัวละครจะอยู่ใน ตัวละครของฉัน

  • สร้างโปรเจกต์: ในช่อง ใส่ในโปรเจกต์ ด้านซ้ายบน เลือก ＋ โปรเจกต์ใหม่… แล้วตั้งชื่อ
  • ตัวละครใหม่: เลือกโปรเจกต์ แล้ววางภาพในกล่องด้านล่าง กล่องจะบอกว่าภาพนี้จะเป็นตัวละครใหม่ในโปรเจกต์ไหน หรือกด ＋ ที่หัวโปรเจกต์ในรายการ
  • หน้าโปรเจกต์ (คลิกชื่อโปรเจกต์ในรายการ): ตั้งค่าที่ทุกตัวละครใช้ร่วมกัน ได้แก่ สไตล์ภาพ (ประโยคภาษาอังกฤษที่ใส่ในทุก prompt) แนวตัวละคร ความละเอียด sprite และภาพอ้างอิงสไตล์ (ดาวน์โหลดไปแนบให้ AI พร้อม prompt) ตัวละครแต่ละตัวยังตั้งเองทับได้ · ปุ่ม ดาวน์โหลดทั้งโปรเจกต์ (zip) และ เพิ่มทุกตัวลง Playtest ไว้ดูว่าขนาดและสไตล์เข้ากันไหม
  • ย้ายตัวละคร ไปโปรเจกต์อื่น: ช่อง 📁 โปรเจกต์: ในการ์ดข้อมูลตัวละคร
  • เปลี่ยนภาพต้นแบบ ของตัวเดิม (เช่นได้ภาพใหม่ที่พื้นหลังเรียบกว่า): ปุ่ม 🔄 เปลี่ยนภาพต้นแบบ ในการ์ดข้อมูลตัวละคร ภาพท่าทางที่วาดไว้ยังอยู่ ติ๊ก และเดาข้อมูลใหม่ ถ้าอยากให้ระบบเดาประเภทและสีจากภาพใหม่
  • ในเครื่อง ตัวละครอยู่ที่ projects/<โปรเจกต์>/<ตัวละคร>/ และ sprite ที่ renders/<โปรเจกต์>/<ตัวละคร>/ copy โฟลเดอร์โปรเจกต์ไปเก็บหรือส่งต่อได้ทั้งชุด

① อัปโหลดตัวละคร

  1. ในแท็บ Pipeline วางภาพที่ช่อง วางภาพ concept ที่นี่ (แถบซ้าย) จะพิมพ์ชื่อก่อนก็ได้
  2. เลือกวิธีกรอกข้อมูลตัวละคร ค่าเริ่มต้นคือ กรอกเอง (ไม่ใช้ AI) ไม่ต้องมีอะไรเพิ่ม
  3. ระบบลบพื้นหลังให้ ถ้าเป็นแผ่น turnaround จะแยกเป็นมุมให้เอง

อัปโหลด 1 ครั้ง = ตัวละครใหม่ 1 ตัว ในโปรเจกต์ที่เลือกในช่อง ใส่ในโปรเจกต์ (กล่องวางภาพบอกไว้) คลิกตัวละครในรายการเพื่อเปิด กล่องใหญ่ทางซ้ายสร้างตัวละครใหม่เสมอ · ภาพมุมอื่นของตัวละครเดิม วางที่ขั้น ③ · ถ้าจะเปลี่ยนภาพต้นแบบ กด 🔄 เปลี่ยนภาพต้นแบบ ที่ขั้น ②

การ์ดทุกใบมีเลขขั้นตอนในวงกลมตัวใหญ่ (①–⑤) วงสีฟ้าคือขั้นที่ต้องทำต่อ · ภาพแต่ละแบบวางที่ขั้นของมันเอง: ภาพตัวละครที่ ① ภาพมุมอื่นที่ ③ ภาพท่าทางจาก AI ที่ ④

② ข้อมูลตัวละคร และคำบรรยาย

เปิดการ์ด ข้อมูลตัวละคร ช่องสำคัญที่สุดคือ คำบรรยาย (อังกฤษ) เพราะทุก prompt วาดภาพขึ้นต้นด้วยประโยคนี้ AI จะได้วาดตัวเดิมทุกครั้ง

  • บรรยายทรงผม หน้า ชุดแต่ละชิ้นพร้อมสี และรองเท้า ให้ละเอียด
    ตัวอย่าง: “a young swordswoman with long red hair in a braid, silver plate armour with gold trim, a red cape, brown leather boots”
  • ไม่ต้องใส่อาวุธ (มีช่องของตัวเองในการ์ดอาวุธ) และไม่ต้องใส่สัดส่วนร่างกาย (เลือกที่ แนวตัวละคร)
  • แนวตัวละคร: ผอมเพียว (สูงราว 5 หัว ค่าเริ่มต้นของตัวละครคน), chibi (ราว 2.5 หัว) หรือ ตามภาพต้นแบบ
  • ทรงตัว (2 ขา, 4 ขา ฯลฯ) มีผลกับสาย 3D (ไม่บังคับ) เท่านั้น

ตรวจเรียบร้อยแล้วกด ✓ ยืนยันข้อมูล ในขั้น ② ถ้าเลือกให้ผู้ช่วย AI (หรือ Claude API) จำแนก ระบบจะกรอกให้ แต่ยังแก้เองได้ หรือกด ✍ กรอกเองแทน ถ้าไม่อยากรอ

③ ภาพอ้างอิง (ไม่บังคับ)

มีภาพหน้า 1 ภาพก็ทำต่อได้ แต่ถ้ามีภาพด้านหลัง AI จะวาดแถวหลังเฉียง (ทรงผม ผ้าคลุม ด้านหลังชุด) ได้แม่นขึ้น

ถ้ายังขาดมุม การ์ด มุมมองตัวละคร (Turnaround) จะมี prompt ให้ คัดลอก แนบภาพหน้าใน AI แล้ววางภาพที่ได้ในการ์ดเดียวกัน (หรือวางลงช่องมุมที่ว่างโดยตรง) หรือที่ขั้น ③ ของแถบขวา สลับมุมหรือกลับซ้าย-ขวาได้ด้วยปุ่มใต้แต่ละภาพ

อาวุธ

เลือกอาวุธก่อนคัดลอก prompt วาดท่าทาง เพราะประเภทอาวุธกำหนดท่าโจมตีใน prompt และแผ่นท่า

  • ประเภทอาวุธ: คฑา/ไม้เท้า มีด ดาบ หอก ธนู ปืน ขวาน กระบอง ประเภทที่ท่าโจมตีแบบเดียวกัน (ฟัน / แทง / ยิงธนู / ยิงปืน) สลับกันได้อิสระ ถ้าต่างแบบต้องวาดท่าโจมตีใหม่ ธนูถือมือซ้าย
  • อาวุธที่ถือ: บรรยายอาวุธเป็นภาษาอังกฤษ ระบบจะเติม “holding …” ใน prompt ให้
  • แยกอาวุธเป็นชั้น (สำหรับเกมที่เปลี่ยนอาวุธได้): ท่าทางจะวาดมือเปล่าแบบกำมือ แล้วระบบวางอาวุธทับตามมือทุกเฟรม ค่าเริ่มต้นให้อาวุธแสดงเฉพาะตอนโจมตี เพิ่มภาพอาวุธได้ที่ ＋ วางภาพอาวุธ (วาดตั้งตรง ด้ามอยู่ล่าง), 📋 prompt วาดอาวุธ ให้ AI วาด หรือ 🧪 ลองอาวุธตัวอย่าง
  • จุดจับอาวุธ: เลือกท่าและมุม คลิกเฟรม ลากเพื่อย้ายมือ ใช้ล้อเมาส์หรือแถบเลื่อนเพื่อหมุน ติ๊ก อยู่หลังตัว ถ้าจำเป็น แล้วกด 💾 บันทึกจุดจับ แก้แค่ 2 มุมที่วาด อีก 6 ทิศได้จากการ flip

หมวก และเวอร์ชันขี่สัตว์

  • 🎩 หมวก/ของบนหัว: วางภาพหมวกหรือหมวกเกราะ (หรือกด 📋 prompt วาดหมวก ให้ AI วาด) ระบบวางหมวกบนหัวทุกเฟรม โดยหาตำแหน่งหัวจากภาพจริง หมวกจึงขยับตามตัวละคร และซ่อนตอนนอน เลือกใบที่สวม แล้วปรับขนาดและตำแหน่งด้วยแถบเลื่อน ไฟล์ดาวน์โหลดสำหรับเกมมีหมวกแยกเป็น <ชื่อ>_hat คู่กับ <ชื่อ>_body ให้เกมสลับหมวกได้
  • 🐎 เวอร์ชันขี่สัตว์ (ในการ์ดข้อมูลตัวละคร): บรรยายสัตว์ที่ขี่เป็นภาษาอังกฤษแล้วกด สร้าง จะได้ตัวละครใหม่ในโปรเจกต์เดียวกัน ใช้ภาพอ้างอิงเดิม และคำบรรยายว่าขี่สัตว์ตัวนั้น แล้ววาดท่าทางเหมือนตัวละครปกติ

④ ให้ AI วาดท่าทาง (ขั้นหลัก)

ในการ์ด ท่าทาง (วาดด้วย AI):

  1. เลือก AI (Gemini, ChatGPT หรืออื่นๆ) แล้วกด 📋 ทุกท่า (prompt เดียว) prompt จะถูกคัดลอกไว้ ถ้าตัวละครร่ายเวท ให้ติ๊ก มีโจมตีเวท ก่อน และติ๊กท่าเพิ่มเติมที่ต้องการ ได้แก่ วิ่ง นั่ง นอนหลับ ดีใจ (เพิ่มท่าละ 2 แถว) ส่วน มุมข้าง (ซ้าย/ขวา) เพิ่มแถวมุมข้างทุกท่า ตอนเดินซ้าย/ขวาจะเห็นด้านข้างจริงแทนภาพหน้าเฉียง (วาดเพิ่มท่าละ 1 แถว)
  2. กด 🦴 แผ่นท่า เพื่อดาวน์โหลดภาพหุ่นเส้นของ prompt นั้น
  3. ใน AI ให้แนบ 2 ภาพ คือภาพตัวละคร (แผ่น turnaround หรือภาพหน้า) กับแผ่นท่า แล้ววาง prompt หรือแนบแค่ 🧩 ภาพเดียว (ตัวละคร + แผ่นท่า) ที่รวมทั้งสองไว้ในภาพเดียว
  4. บันทึกภาพที่ AI ส่งกลับมา แล้ววางที่ช่อง ⬇ วางภาพที่ AI วาดให้ที่นี่ ใต้ปุ่ม prompt

ระบบตัดตารางเป็นทุกท่าทุกมุม ตรวจทีละแถว จัดเท้าให้ตรง ทำ 8 ทิศ และประกอบ sprite ให้เอง ผลจะขึ้นในการ์ดเดียวกันและการ์ดด้านล่าง

อ่านผลตรวจ

  • ✓ n เฟรม — แถวนี้ใช้ได้
  • ⚠ ได้ n เฟรม (ขอ 6) — AI วาดเฟรมมากหรือน้อยเกินไป (ต่างไป 1 เฟรมไม่เป็นไร)
  • ⚠ ขนาดตัวแกว่ง n% — ความสูงตัวละครต่างกันระหว่างเฟรมตั้งแต่ 12% ขึ้นไป
  • ⚠ ขาแทบไม่สลับ (ท่าเดิน) — AI วาดท่าก้าวท่าเดียวซ้ำ

วิธีซ่อมแถว: กด 📋 ทั้ง 2 มุม ของท่านั้น (หรือ 📋 prompt ในช่องเดียว) พร้อม 🦴 ของท่านั้น ให้ AI วาดเฉพาะท่านั้นใหม่ แล้ววางที่ช่องเดิม ระบบจะแทนที่เฉพาะท่านั้น

แก้โดยไม่ต้องวาดใหม่

  • ✎ แก้เฟรม (ในช่องที่มีภาพแล้ว): เลื่อนเฟรมไปก่อน/หลัง ลบ ทำซ้ำ กลับด้านทีละเฟรม ขยับทีละนิด หรือทำเป็นจังหวะค้าง (⏸ ×2–×4 แสดงเฟรมนั้นนานขึ้น เช่นจังหวะฟันโดน) และวางภาพ 1 ภาพเพื่อเพิ่มหรือแทนเฟรมได้ มีตัวอย่างเล่นให้ดูทันที กด 💾 บันทึกเฟรม เพื่อประกอบ sprite ใหม่ หรือ ↺ กลับเป็นภาพที่วาด เพื่อยกเลิกทั้งหมด เฟรมที่ระบบตรวจว่าผิดปกติจะมีกรอบแดง
  • ↶ เอาภาพก่อนหน้าของแถวนั้นกลับมา หลังวางภาพใหม่ทับไปแล้ว (เก็บไว้ 5 ภาพล่าสุด)
  • 🎨 ล็อกสีตามภาพต้นแบบ (เปิดไว้เป็นค่าเริ่มต้น) ปรับสีทุกแถวกลับให้ตรงกับภาพตัวละคร แถวที่วาดคนละรอบจะได้ไม่กะพริบสีต่างกัน
  • ความละเอียด sprite: มาตรฐาน (สูง ~80 px) / HD ×2 / HD ×3 ภาพวาดที่มีรายละเอียดมาก (เกราะ ลวดลาย) ควรใช้ HD ×2 ขึ้นไป ไม่อย่างนั้นจะเบลอ ส่วนความสูง (ม.) ตั้งในการ์ดข้อมูลตัวละคร เช่นออร์คหรือยักษ์ 2–3 ม. เปลี่ยนแล้วระบบประกอบ sprite ใหม่ให้เอง
  • ระบบตรวจยังเตือนเฟรมที่ดูต่างจากเฟรมอื่นในแถว: สีต่าง (หันผิดมุมหรือชุดเปลี่ยน) หรือมีบางส่วนโผล่/หายไป (เช่นอาวุธในท่ายืน/เดิน)

🎨 ให้ผู้ช่วย AI ตรวจงานศิลป์ คัดลอกคำสั่งไปวางในแชทของผู้ช่วย AI (Claude Code, Gemini CLI หรือ Codex): ผู้ช่วยจะดูทุกแถวที่วาดแล้ว (มุมที่หัน ท่าทาง กายวิภาค ความเหมือนต้นแบบ ร่องรอยจาก AI) แล้วเขียนผลและวิธีแก้รายแถว ขึ้นเป็นป้าย 🎨 ในแต่ละช่อง

💡 AI ทำตามท่าที่เห็นได้ดีกว่าท่าที่อธิบายด้วยคำมาก ควรแนบแผ่นท่าทุกครั้ง แขนขาสีน้ำเงิน = ข้างซ้ายของตัวละคร, สีแดง = ข้างขวา, หัวสีเทา = เห็นด้านหลังศีรษะ

⑤ ผลลัพธ์และดาวน์โหลด

การ์ด ผลลัพธ์ + ดาวน์โหลด แสดง sprite ครบ 8 ทิศ และมีปุ่ม:

  • ▶ ทดลองเดิน/โจมตีใน Playtest
  • ⬇ สำหรับเกมเว็บ: zip ที่มี texture atlas (.png / .webp), .json แบบ TexturePacker (ใช้กับ PixiJS Assets.load และ Phaser load.atlas จุด pivot อยู่ที่เท้า), .anim.json ที่บอกเวลาเฟรม การวนซ้ำ และ event (atk = จังหวะทำดาเมจ, step = เสียงก้าว) และ demo.html ที่เล่นครบ 8 ทิศ (ใน zip นี้มีไฟล์ Godot และ Aseprite ด้านล่างให้ด้วย)
  • ⬇ Godot 4: zip ที่มี atlas .png กับไฟล์ .tres แบบ SpriteFrames (1 แอนิเมชันต่อท่าต่อทิศ เช่น walk_S ตั้งความเร็วและการวนซ้ำไว้แล้ว) ก๊อปทั้งโฟลเดอร์ไปไว้ที่รากโปรเจกต์ Godot ตามชื่อเดิม แล้วใส่ใน AnimatedSprite2D ค่า offset ที่ทำให้เท้าอยู่ตรงจุดของโหนดเขียนไว้ใน README แล้ว
  • ⬇ Aseprite JSON: atlas .png กับ JSON รูปแบบเดียวกับที่ Aseprite export (frames เป็นลิสต์ มี frameTags ต่อท่าต่อทิศ และเวลาแต่ละเฟรม) ใช้กับ Phaser (load.aseprite) และตัว import ของ Unity / Godot ได้
  • ▶ เปิด web demo (PixiJS): เปิด demo.html ตัวเดียวกับในไฟล์ดาวน์โหลด ในแท็บใหม่ ได้ทันทีจากเครื่องมือ แสดงครบ 8 ทิศ และมีปุ่มสลับท่า ต้องต่ออินเทอร์เน็ต (โหลด PixiJS จาก CDN) ส่วนไฟล์ demo.html ที่ดาวน์โหลดไป ดับเบิลคลิกเปิดตรงๆ ไม่ได้ (เบราว์เซอร์ไม่ให้อ่านไฟล์ในเครื่อง) ต้องเปิดผ่าน server เช่นพิมพ์ python -m http.server 8080 ในโฟลเดอร์นั้น แล้วเปิด http://localhost:8080/demo.html
  • ⬇ ภาพทั้งหมด (zip): ทุกเฟรมเป็น PNG
  • ไฟล์ดาวน์โหลดสำหรับเกมมี game.json ด้วย: กล่องชน (hitbox), ขนาดเงาใต้เท้า และ จุดปล่อยเวท/กระสุนในแต่ละทิศ ณ เฟรมที่โจมตีโดน ใช้ตรวจการชนและจุดเกิดกระสุนในเกม
  • 🔍 ดูทีละเฟรม / GIF: เปิดหน้าดูทีละเฟรมของตัวละครนี้ เพื่อดาวน์โหลดรายเฟรม แถบภาพ GIF และไฟล์ .spr/.act

เปลี่ยนสีเป็นตัวใหม่

การ์ด 🎨 เปลี่ยนสีเป็นตัวใหม่ ทำ sprite เดิมในสีอื่นโดยไม่ต้องวาดใหม่ เป็นวิธีที่นิยมใช้เพิ่มจำนวนมอนสเตอร์ หรือทำสีประจำทีม คลิกสีของ sprite เพื่อเปลี่ยนเฉพาะกลุ่มสีนั้น (หรือ ทุกสี) หมุนเฉดสี ปรับความสดและความสว่าง ดูตัวอย่าง ตั้งชื่อ แล้วกด ＋ เพิ่มสีใหม่ แต่ละสีเป็น sprite แยกที่มีท่าทางครบเหมือนตัวเดิม เปิดดูได้ด้วย ▶ Demo ดาวน์โหลดได้ และหาเจอใน Playtest กับหน้าดูทีละเฟรม ในชื่อ “ตัวละคร (v1)” เส้นขอบและสีเทาจะไม่ถูกเปลี่ยน
