What ImGen9 does

ImGen9 turns one character image into a game-ready 2D sprite in 8 directions: idle, walk, attack, hurt and die. You get a texture atlas + JSON for web games (PixiJS / Phaser), frame images, GIFs, and .spr/.act files.

ImGen9 does not draw. Your own image AI (Gemini, ChatGPT, …) draws, from prompts ImGen9 writes for you. ImGen9 does the tedious parts around it: background removal, cutting frames, checking them, lining up the feet, making 8 directions out of 2 drawings, and packing.

① Upload② Describe③ Reference views (optional) ④ AI drawings⑤ Download

The steps are listed in the right panel of the Pipeline tab. The step marked as next is open; finished steps show ✓. The bar at the top of the page names the next step (press Go there ↓), and every card has a badge: Required · Optional (skip it, e.g. reference views, weapon, headgear, colour variants) · Automatic · ✓ Done.

Before you start

  • An image AI account that can take attached images: Google Gemini or ChatGPT both work.
  • A character image you made yourself or have the rights to: one character, full body, plain background. A turnaround sheet (front / 3/4 / side / back side by side) works even better.
  • The very first background removal downloads a model (~180 MB) once, so the first upload takes a minute. After that it takes a few seconds.

💡 No character yet? Ask your image AI for a turnaround sheet first. A good request: “Character design turnaround sheet for a 2D isometric RPG: [who, hair, outfit, colours, weapon]. Four full-body views side by side (front, front three-quarter facing bottom-left, side facing left, back), relaxed standing pose, plain white background, no shadows, no text.”

🔌 Connections

The 🔌 Connections button in the top bar (it opens by itself the first time) shows what is Required and what is Not required, checked on your PC only:

  • Required: an image AI on the web (Gemini or ChatGPT) to draw the poses. Pick yours; every prompt is written for it.
  • Not required: an AI assistant in a chat — Claude Code, Gemini CLI or Codex, whichever is installed — to fill in the character info and review drawings; API keys (shown only as set / not set); Blender for the 3D route.

Without the optional ones the tool still works: you type the character description yourself. ImGen9 never looks at your browser or your sign-ins.

Projects and characters

A project is the characters of one game (or one theme), e.g. “My RPG”. Every character is in a project; until you make one, characters go into My characters.

  • New project: in Add to project at the top left, pick ＋ New project… and name it.
  • New character: pick the project, then drop an image in the box below it; the box says which project the new character goes into. Or press ＋ on a project in the list.
  • Project page (click a project's name in the list): settings every character shares — the Art style (an English sentence added to every prompt), Character style, Sprite detail and a Style reference image (download it and attach it to the AI with the prompt). A character can still set its own. Plus Download the whole project (zip) and Add every character to Playtest to check that sizes and styles match.
  • Move a character to another project: 📁 Project: in its Character info card.
  • Replace the concept image of a character (say, a new picture with a plainer background): 🔄 Replace the concept image in its Character info card. The drawn poses stay; tick and guess the info again to have type and colours guessed from the new image.
  • On disk a character lives in projects/<project>/<character>/ and its sprite in renders/<project>/<character>/, so copying a project folder copies the whole set.

① Upload a character

  1. In the Pipeline tab, drop the image on Drop a concept image here (left panel). Optionally type a name first.
  2. Choose how to fill in character info. Fill in yourself (no AI) is the default and needs nothing else.
  3. ImGen9 removes the background. A turnaround sheet is split into views automatically.

Each upload creates a character in the project chosen under Add to project (the box says which). Click a character in the list to open it. To add more views to the same character, use the drop zone in step ① of the right panel — the big box on the left always starts a new character.

② Character info and description

Open the Character info card. The most important field is Description (English): every drawing prompt starts with it, so the AI draws the same character every time.

  • Describe hair, face, outfit pieces and their colours, shoes. Be specific.
    Example: “a young swordswoman with long red hair in a braid, silver plate armour with gold trim, a red cape, brown leather boots”.
  • Leave out the weapon (it has its own field in the Weapons card) and body proportions (chosen with Character style).
  • Character style: slender (about 5 heads tall, the default for people), chibi (about 2.5 heads), or follow the reference image.
  • Body type (two legs, four legs, …) matters for the optional 3D route only.

Press ✓ Confirm info in step ② when it looks right. If you chose an AI assistant (or the Claude API), the fields are filled in for you; you can still edit them, or press ✍ Fill in by hand instead instead of waiting.

③ Reference views (optional)

One front image is enough to continue. A back view helps the AI draw the back 3/4 rows correctly (hair, cape, back of the outfit).

If views are missing, the Character views (turnaround) card shows a ready prompt: copy it, attach your front image in your image AI, and drop the result in step ① of the right panel. Views can be swapped or flipped with the controls under each picture.

Weapons

Choose the weapon before copying drawing prompts: the weapon type decides which attack the prompts and the pose guide ask for.

  • Weapon types: staff, dagger, sword, spear, bow, gun, axe, mace. Types with the same attack style (swing / thrust / bow / gun) can be swapped freely; a different style needs a new attack drawing. A bow sits in the left hand.
  • Held weapon: describe the weapon in English. It is added to the prompts as “holding …”.
  • Weapon as a separate layer (for games that swap weapons): the poses are drawn with empty, gripping hands and the weapon is laid over each frame at the hand. By default it shows only in attacks. Add weapon pictures with ＋ Drop a weapon image (drawn upright, handle down), 📋 Weapon prompt to have the AI draw one, or 🧪 Try a sample weapon.
  • Weapon grip editor: pick an action and view, click a frame, drag to move the hand, use the mouse wheel or slider to rotate, tick Behind the body where needed, then 💾 Save grip. Edit only the 2 drawn views; the other 6 directions follow by flipping.

Headgear and mounted versions

  • 🎩 Headgear: drop a picture of a hat or helmet (or copy 📋 Prompt to draw the headgear for your image AI). It is laid on the head of every frame — found from the drawing, so it follows bobbing and leaning — and hidden while lying down. Pick which one is worn, adjust size and position with the sliders. Game downloads also get it alone as <name>_hat, next to <name>_body, so a game can swap headgear.
  • 🐎 Mounted version (in the character card): describe the mount in English and press Create. You get a new character in the same project, with the same references, described as riding it; draw its actions like any character.

④ AI drawings (the main step)

In the Poses (AI-drawn) card:

  1. Pick your AI (Gemini, ChatGPT or other) and press 📋 All actions (one prompt). The prompt is copied. Tick Has a magic attack first if the character casts spells, and any Extra actions it needs — run, sit, sleep, happy (2 more rows each). Side view (W/E) adds a profile row per action: walking left/right then looks like a true side view instead of the front 3/4 drawing (one more row per action to draw).
  2. Press 🦴 Pose guide to download the stick-figure sheet for that prompt.
  3. In your image AI, attach 2 images — your character (turnaround or the front image) and the pose guide — then paste the prompt. Or attach just 🧩 1 image (character + poses), which puts both on one board.
  4. Save the image the AI returns and drop it on ⬇ Drop the AI-drawn image here, right under the prompt buttons.

ImGen9 cuts the grid into every action and view, checks each row, lines up the feet, makes the 8 directions and builds the sprite on its own. Results appear in the same card and below.

Reading the checks

  • ✓ n frames — the row is fine.
  • ⚠ Got n frames (asked for 6) — the AI drew too many or too few frames (one more or less is fine).
  • ⚠ Body size wobbles n % — the character changes height between frames by 12 % or more.
  • ⚠ Legs barely alternate (walk) — the AI repeated one stepping pose.

To fix a row, press 📋 Both views next to that action (or 📋 prompt in one cell) with its 🦴, have the AI redraw just that, and drop the result in the same drop zone — it replaces only that action.

Fixing without redrawing

  • ✎ Edit frames (on a drawn cell): move frames earlier/later, delete, duplicate, flip one frame, nudge it a few pixels, or make it a pause (⏸ ×2–×4 — shows the frame longer, e.g. at the moment of the hit). You can also drop a single image to add or replace one frame. The preview plays the result; 💾 Save frames rebuilds the sprite, ↺ Reset to the drawing undoes all edits. Frames the check found odd have a red outline.
  • ↶ brings back the previous drawing of a row after you dropped a new one (the last 5 are kept).
  • 🎨 Lock colours to the reference (on by default) pulls every row's colours back to your character image, so rows drawn at different times don't flicker.
  • Sprite detail: Classic (~80 px tall) / HD x2 / HD x3. Detailed, painted art (armour, ornaments) needs HD x2 or more, or it blurs. Set Height (m) in the character info card, e.g. 2–3 m for an orc or a giant. The sprite rebuilds on its own after a change.
  • The check also flags frames that look different from the rest of their row: other colours (wrong view or outfit) or a part that appears/disappears (e.g. the weapon in idle/walk).

🎨 Ask your AI assistant for an art review copies a request to paste into the chat of your AI assistant (Claude Code, Gemini CLI or Codex): it looks at every drawn row (facing, motion, anatomy, likeness, AI artefacts) and writes a verdict and what to fix per row; it shows as a 🎨 badge on each cell.

💡 AIs follow a pose they can see much better than one described in words: always attach the pose guide. Blue limbs are the character's left, red its right; a grey head means the back of the head.

⑤ Results and download

The Result + downloads card shows the sprite in 8 directions and offers:

  • ▶ Try walk/attack in Playtest
  • ⬇ For web games (PixiJS / Phaser): a zip with the texture atlas (.png / .webp), a TexturePacker-style .json (PixiJS Assets.load, Phaser load.atlas; the pivot is at the feet), .anim.json with frame times, loops and events (atk = apply damage, step = footstep), and a demo.html that plays all 8 directions. It also holds the Godot and Aseprite files below.
  • ⬇ Godot 4: the atlas .png plus a SpriteFrames .tres with one animation per action and direction (e.g. walk_S), speed and looping already set. Copy the folder into the root of your Godot project under its own name and use it in an AnimatedSprite2D; the README gives the offset that puts the feet on the node.
  • ⬇ Aseprite JSON: the atlas .png plus the sprite-sheet JSON Aseprite itself exports (frames array, a frameTags entry per action and direction, per-frame durations). Phaser (load.aseprite) and Unity / Godot Aseprite importers read it.
  • ▶ Web demo (PixiJS): opens the demo.html from that download in a new tab, straight from ImGen9 — all 8 directions with a button per action. Needs an internet connection (PixiJS loads from a CDN). The downloaded demo.html can't be opened by double-clicking (browsers block local files): serve its folder, e.g. python -m http.server 8080, then open http://localhost:8080/demo.html.
  • ⬇ All images (zip): every frame as PNG.
  • Game downloads also include game.json: the hitbox, the ground shadow size and, per direction, the cast point where an attack or spell leaves the hand at the hit frame — handy for collisions and for spawning projectiles.
  • 🔍 Frame by frame / GIF: opens this character frame by frame, for single frames, strips, GIFs and the .spr/.act files.

Colour variants

The 🎨 Colour variants card makes the same sprite in other colours without redrawing — a common way to get more monsters or team colours. Click one of the sprite's colours to change only that group (or All colours), turn its hue, adjust saturation and brightness, watch the preview, name it and press ＋ Add variant. Each variant is its own sprite with the same animations: play it with ▶ Demo, download it, or find it in Playtest and the frame-by-frame view as “character (v1)”. Outlines and greys are never recoloured.

Playtest

Test characters the way a game would. Add one from Your renders on the left.

  • Playground: walk with WASD / arrow keys or click the ground; Space attacks the nearest training dummy; right-drag pans, wheel zooms.
  • Lineup: everyone side by side doing the same action, to compare timing.
  • 8 Dirs: the selected character in all 8 directions at once.
  • Treadmill: if the feet slide against the moving ground, adjust Game speed. Slow motion (0.25×) shows each frame.
  • 💾 Save stores speed, hit frame and range with the character; they are included in exports.
  • Characters with weapon layers have a weapon picker to swap weapons live.

Frame by frame (Sprite Inspector)

Opened with 🔍 Frame by frame / GIF in a character's result card: play any action in any direction frame by frame, see frame times, damage events, layers and anchors, and download frames, strips or GIFs. The list on the left shows that character with its weapon layers and colour variants. Press ← Back to Pipeline to return. It shows only sprites made with ImGen9.

Troubleshooting

The first upload seems stuck
It is downloading the background-removal model (~180 MB) once. Wait a minute.
“Expected 10 rows…” or rows mixed up
The AI didn't draw the grid as asked (front and back mixed in one row, figures overlapping). Redraw; attaching the pose guide helps a lot. 7 columns instead of 6 is fine.
The legs don't alternate when walking
Redraw the walk only (📋 Both views + 🦴 on the walk row). The pose guide shows each leg position.
The weapon disappears in some frames, or there are two weapons
Without a weapon layer, make sure the weapon is described in the Weapons card. With a weapon layer on, poses drawn earlier still contain the weapon: redraw them empty-handed.
Thin parts (staff, hair strands) are cut off
Start with REMBG_MODEL=isnet-anime for stylised art, and keep REMBG_POST_PROCESS off.
The character looks chibi but you wanted slender
Check Character style. A reference image with a big head pulls the AI toward chibi: redraw the turnaround in slender proportions first and use that as the reference.
Something looks outdated after an update
Reload the page with Ctrl+F5.

Your images and rights

  • Use images you made or have the rights to. Don't use screenshots of other people's art.
  • You own what you put in and what you get out. Images made with an AI are also subject to that service's terms; check them before selling assets, and disclose AI use where a store asks.
  • ImGen9's prompts describe a look in plain words and never name other games or artists.
  • ImGen9 is open source (AGPL-3.0) and not affiliated with any game publisher; the .spr/.act support is for compatibility only.
