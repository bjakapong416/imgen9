# จากภาพเดียว → ตัวละครพร้อมใช้ในเกม: อะไรอัตโนมัติ อะไรต้องทำเอง

ImGen9 เปลี่ยนภาพตัวละคร 1 ภาพให้เป็น sprite 2D ครบ 8 ทิศ ส่วนที่วาดภาพคือ AI วาดภาพของคุณเอง (Gemini / ChatGPT)
จาก prompt และแผ่นท่าที่เครื่องมือเขียนให้ ส่วนงานจุกจิกรอบ ๆ (ลบพื้นหลัง ตัดเฟรม ตรวจ จัดเท้า ทำ 8 ทิศ ประกอบไฟล์) เครื่องมือทำเอง

## สรุป

| ส่วน | สถานะ | ใครทำ |
|---|---|---|
| ข้อมูลตัวละคร + คำบรรยายภาษาอังกฤษ (`description_en`) | ✅ พิมพ์เอง หรือให้ผู้ช่วย AI (Claude Code / Gemini CLI / Codex) กรอกในแชท | คุณ / ผู้ช่วย AI |
| ยืน เดิน โจมตี เจ็บ ตาย (8 ทิศ) | ✅ AI วาด 2 มุม (หน้าเฉียง + หลังเฉียง) แล้ว flip เป็น 8 ทิศ | AI วาดภาพ → เครื่องมือ |
| โจมตีด้วยเวท (cast) | ✅ ติ๊ก "มีโจมตีเวท" ในการ์ดท่าทาง | AI วาดภาพ |
| ท่าเพิ่ม: วิ่ง นั่ง นอน ดีใจ | ✅ ติ๊กใน "ท่าเพิ่มเติม" | AI วาดภาพ |
| มุมข้าง (ซ้าย/ขวาเป็นภาพข้างจริง) | ✅ ติ๊ก "มุมข้าง" (ไม่บังคับ) | AI วาดภาพ |
| อาวุธ / หมวก แยกชั้น (เปลี่ยนในเกมได้) | ✅ การ์ดอาวุธ / หมวก (ไม่บังคับ) | AI วาดภาพ → เครื่องมือ |
| สีใหม่ (palette swap) | ✅ การ์ดเปลี่ยนสี | เครื่องมือ |
| ไฟล์สำหรับเกม | ✅ เว็บ (PixiJS / Phaser), Godot 4, Aseprite JSON, `.spr`/`.act`, zip ทั้งโปรเจกต์ | เครื่องมือ |
| เอฟเฟกต์สกิล | ⏸ ยังไม่อยู่ในเวอร์ชันนี้ | – |

## ขั้นตอน (เส้นทาง 2D)

```
① วางภาพตัวละคร (ภาพเดียวหรือแผ่น turnaround) → ลบพื้นหลัง + แยกมุมให้เอง
② ข้อมูลตัวละคร + คำบรรยายภาษาอังกฤษ (พิมพ์เอง หรือพิมพ์ในแชทผู้ช่วย AI ว่า "จำแนกตัวละคร <ชื่อ>")
③ ภาพมุมอื่น (ไม่บังคับ)
④ การ์ด "ท่าทาง": 📋 คัดลอก prompt + 🦴 แผ่นท่า → ให้ AI วาด → วางภาพที่ได้ในกล่องใหญ่
   ระบบตัดตาราง (แถวละ 1 ท่า 1 มุม, 6 เฟรม) ตรวจ จัดเท้า ทำ 8 ทิศ และประกอบ sprite เอง
   แถวไหนขึ้น ⚠ ใช้ prompt ของท่านั้นวาดใหม่ หรือ ✎ แก้เฟรม
⑤ ลองเดินใน Playtest → ดาวน์โหลด
```

| ท่า | เฟรม | เวลา/เฟรม | หมายเหตุ |
|---|---|---|---|
| ยืน (idle) | 6 | 120 ms | loop |
| เดิน (walk) | 6 | 100 ms | loop, event `step` 2 ครั้งต่อรอบ |
| โจมตี (attack) | 6 | 130 ms | ง้าง 1-2, ฟัน 3-4, กลับท่า 5-6 · event `atk` ที่ราว 59% ของท่า (ปรับใน Playtest ได้) |
| โจมตีเวท (cast) | 6 | 120 ms | ไม่วาดเอฟเฟกต์ลงในตัวละคร |
| เจ็บ (damage) | 6 | 80 ms | |
| ตาย (die) | 6 | 240 ms | เฟรมสุดท้ายนอนกับพื้น |
| วิ่ง / นั่ง / นอน / ดีใจ | 6 | 70 / 200 / 260 / 110 ms | ท่าเพิ่มเติม |

**2 ภาพแทน 8 ทิศ** (sprite เกม 2D ส่วนใหญ่ทำแบบนี้): S, SW, W ← ภาพหน้าเฉียง · SE, E ← ภาพหน้าเฉียงกลับด้าน ·
NW ← ภาพหลังเฉียง · N, NE ← ภาพหลังเฉียงกลับด้าน (ถ้าวาดมุมข้าง W/E จะใช้ภาพข้างแทน)

**การตรวจอัตโนมัติ (ต่อแถว):** จำนวนเฟรม ความสูงตัวละครแกว่งเกิน 12% ขาไม่สลับ (ท่าเดิน)
เฟรมที่สีหรือรูปร่างต่างจากเฟรมอื่น ส่วนที่ตัวเลขวัดไม่ได้ (ท่าทางอ่านออกไหม หน้าเหมือนต้นแบบไหม) ให้ผู้ช่วย AI
ตรวจงานศิลป์ได้ด้วยคำสั่ง "ตรวจงานตัวละคร <ชื่อ>"

**ข้อจำกัด:**
- AI วาดแต่ละเฟรมไม่เหมือนกันเป๊ะ เวลาเล่นต่อกันอาจเห็นภาพสั่น ล็อกสีตามภาพต้นแบบช่วยได้ ถ้ามากเกินไปให้วาดใหม่
- AI บางครั้งวาดเฟรมไม่ครบหรือติดกัน ระบบจะเตือน
- Claude วาดภาพไม่ได้ ใช้ Gemini หรือ ChatGPT สำหรับขั้นวาด

## ไฟล์ที่ได้

- ในเครื่อง: `renders/<โปรเจกต์>/<ตัวละคร>/sprite/` มี `<ตัวละคร>.spr` + `.act`, `build.json` (รายงานการประกอบ) และ
  `game.json` (กล่องชน เงา จุดปล่อยกระสุน)
- ดาวน์โหลด (การ์ด "ผลลัพธ์ + ดาวน์โหลด"): ชุดเกมเว็บ (atlas + JSON + `demo.html`), Godot 4 (`.tres`), Aseprite JSON,
  ภาพทั้งหมด (zip) และ 🔍 ดูทีละเฟรม / GIF
- หน้าโปรเจกต์: ดาวน์โหลดทุกตัวละครในโปรเจกต์เป็น zip เดียว `<โปรเจกต์>.zip`
- ทุกเฟรมมีจุดเท้าตรงกัน สลับท่าแล้วตัวละครไม่กระตุก

# เส้นทางเสริม: 3D (ปิดไว้ · ทดลอง)

```
วางรูป → แยกมุม → สร้างโมเดล 3D ในเครื่อง (Hunyuan3D-2mv) → ตรวจโมเดล → ใส่กระดูก + ท่า → render 8 ทิศ (Blender) → .spr/.act
```
เปิดด้วย `AUTO_LOCAL_3D=1` (ติดตั้ง Hunyuan3D-2 เองและตั้ง `HUNYUAN_PYTHON`) หรือวางไฟล์โมเดลจากบริการอื่นเอง
ผลที่ได้ยังไม่ตรง concept พอสำหรับใช้ในเกม จึงไม่ใช่เส้นทางหลัก รายละเอียดการ render อยู่ใน [PIPELINE.md](PIPELINE.md)

- ใช้ GPU NVIDIA (ทดสอบบนการ์ดระดับ RTX 4060 ได้ผลใน ~4 นาทีต่อตัว) ส่วนลงสีใช้วิธีฉายภาพหน้า/ข้าง/หลังลงโมเดลใน Blender
- **ไลเซนส์ Hunyuan3D-2:** Tencent Hunyuan Community License ห้ามใช้ใน EU / UK / เกาหลีใต้ ควรอ่านเงื่อนไขก่อนใช้เชิงพาณิชย์
- ใส่กระดูก: ทรงคนใช้ Mixamo · สัตว์ใช้ Blender Rigify / Auto-Rig Pro ถ้าโมเดลยังไม่มีกระดูก ระบบใช้ท่าแบบ "ขยับทั้งตัว"
  (ยืด หด กระโดด พุ่ง) ไปก่อน
- ภาพ render มีแสงเงาแบบ 3D ส่วน concept เป็นภาพวาด 2D ลายเส้นจึงไม่ตรงกัน

## การแบ่งงาน

- **ส่วนที่ต้องใช้วิจารณญาณ** (จำแนกตัวละคร วางแผนท่าและสกิล ตรวจงานศิลป์): ผู้ช่วย AI ในแชท (Claude Code / Gemini CLI / Codex)
  ไม่ต้องใช้ API key · คำสั่ง: `จำแนกตัวละคร <ชื่อ>` และ `ตรวจงานตัวละคร <ชื่อ>` · ผู้ช่วยใช้ `python -m tools.ai_tasks` (ดู CLAUDE.md)
- **งานเครื่องมือ** (ลบพื้น ตัด ตรวจ ประกอบ export): เครื่องมือทำเอง
- ถ้าอยากให้จำแนกอัตโนมัติโดยไม่ใช้แชท เลือก "Claude API" ได้ แต่ต้องตั้ง `ANTHROPIC_API_KEY` และเสียค่าใช้จ่ายรายครั้ง
